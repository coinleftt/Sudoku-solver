# Sudoku solver
Sudoku solver with full annotations

Algorithms:
- Pencil and Paper
- Backtracking


## Installation

Clone the project:

```bash
  git clone https://github.com/coinleftt/Sudoku-solver
  cd Sudoku-solver
```
    
Edit Soduku data in "sudoku.txt" file. Then, run with:

```bash
  python main.py
```

4 Latex files will be generated, convert them into PDF files using online converter.
